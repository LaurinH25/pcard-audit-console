Downloading transaction file…

Static build — runs entirely in your browser (SQLite via sql.js, no server). The transaction database downloads once per visit (~98 MB) directly from this repository's Git LFS storage.

Ask a question in plain English

Your question is translated into a SQLite query, run against the transaction file, and returned with the query shown so you can verify what was actually asked. Read the SQL before you rely on the numbers — a question that reads clearly can still translate into the wrong filter.

This runs entirely in your browser, so there's no server to hold a shared API key. Paste your own Google AI (Gemini) key to use this tab — get a free one at aistudio.google.com/apikey. It's saved only in this browser's local storage and sent directly to Google, never to any server of ours.

Search for prohibited purchases

    
OSU prohibits P-Card use for alcohol, cash advances, decorations,
      donations and sponsorships, gasoline, gift cards, insurance, late fees, postage,
      moving expenses, personal purchases, individual memberships, salaries and benefits,
      and service or incentive awards. Two search routes are offered because these
      purchases hide in different places.


    
    
      
  1. Pick the year you are auditing.
    2. 
      
  2. Search the description for what was bought — this catches
        line-item text such as “gift card”, and is the better route for alcohol,
        awards and decorations.
    3. 
      
  3. Search the vendor for who was paid — this catches merchants
        such as USPS or a liquor store even when the description is only
        “GENERAL PURCHASE”, which is the case for two thirds of all rows.
    4. 
      
  4. Review the results, then pull the receipt and the business purpose recorded
        in Works for anything you flag. A hit is a question, not a finding.
